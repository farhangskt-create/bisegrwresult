.# BISE Gujranwala SSC 2025 Gazette Search

A fast Streamlit application for searching the BISE Gujranwala SSC First Annual Examination 2025 Gazette.

## Features

- Search by Roll Number
- Search by Student Name
- SQLite Database
- Fast Search
- Streamlit UI

## Technology

- Python
- PyMuPDF
- SQLite
- Streamlit
